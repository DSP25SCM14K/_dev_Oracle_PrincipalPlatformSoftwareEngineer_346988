# Dev Kumar — Cloud Platform & AI Systems Portfolio

A responsive portfolio focused on multi-tenant cloud platforms, distributed data systems, workflow orchestration, governed AI integrations, and production operations. The animated background and live data-to-AI diagram trace sources through ingestion, catalog governance, workflows, and observability.

Open `index.html` directly or serve this folder as a static site. GitHub Pages publishes the repository root from `main`.

- `index.html` — portfolio, all 16 experience bullets, project links, and platform diagrams
- `styles.css` — responsive design and motion
- `script.js` — animated background, rotating focus text, reveal effects, and project search
- `ROLE_RESEARCH.md` — Oracle and role analysis with public sources
- `.nojekyll` — preserve static asset paths on GitHub Pages
